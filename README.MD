# Victory Life Church Management System

A professional, mobile-responsive Church Management System built with pure HTML, CSS, and JavaScript.

## Features

- **Dashboard** - Real-time statistics and activity feed
- **Member Management** - Add, edit, view, and delete members
- **Member Profiles** - View member details and giving history
- **Attendance Tracking** - Record and track member attendance
- **Finance Management** - Track tithes, offerings, and expenses
- **Event Management** - Create and manage church events
- **Reports** - Generate and export reports
- **Settings** - Configure system settings
- **Dark Mode** - Toggle between light and dark themes
- **Mobile Responsive** - Works on all screen sizes

## Setup Instructions

1. Clone or download the repository
2. Open `index.html` in your browser
3. Login with demo credentials: `admin@church.com` / `password123`
4. Start managing your church!

## Data Storage

All data is stored locally in your browser's localStorage. No database or server is required.
